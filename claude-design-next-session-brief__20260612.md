## Как использовать Variant Switcher (Фреска / Студия / Мрамор)

### Когда какой вариант обложки применять:

| Вариант | Контекст | Аудитория |
|---------|---------|-----------|
| **Фреска** | Публичные материалы, лендинги, презентации для клиентов | Предприниматели, незнакомые с брендом |
| **Студия** | Внутренние доки, обучающие материалы курса, white papers | Участники курса, команда |
| **Мрамор** | Корпоративные предложения, B2B-документы, печатные материалы | Партнёры, корпоративные клиенты |

### Практическое использование в Claude Design:
- Переключать variant только на секции "Обложка" — остальной контент одинаков
- При экспорте в PDF — сначала выбрать нужный вариант, потом скриншотить/печатать
- Мрамор даёт светлый фон — удобен для распечатки на обычном принтере (экономия тонера)

## Артефакты, которых не хватает

Попросить Claude Design создать в следующих сессиях:

1. **Social Media Kit** — набор из 5-6 шаблонов для Telegram/ВКонтакте (разные форматы)
2. **Цветовые свотчи для Figma** — экспорт палитры как Figma-переменные (CSS custom properties)
3. **Типографическая шкала в таблице** — все размеры, веса, line-height одним блоком
4. **"Что нельзя" с визуальными примерами** — расширить секцию 07: добавить скриншоты реальных ошибок
5. **Email-подпись CEO** — шаблон для Gmail (HTML-код готов к вставке)

## Технические советы для работы с Claude Design

### Редактирование текста:
- Кликнуть на текст в превью → появится поле редактирования прямо в интерфейсе
- Изменения синхронизируются в реальном времени в HTML

### Добавление секций:
- Попросить Claude добавить секцию — он создаёт её в HTML и добавляет в навигацию автоматически
- Промпт: "Добавь секцию [название] после секции [номер]"

### Экспорт:
- Кнопка "Download" экспортирует как .dc.html — не обычный HTML
- Для чистого HTML: попросить "Создай статическую версию без dc-элементов"
- Для PDF: открыть в Chrome → Ctrl+P → Сохранить как PDF (выбрать масштаб 80%)

### Работа с вариантами:
- variant switcher живёт в JS-состоянии компонента (state.cover: 'a'|'b'|'c')
- При следующем открытии файла — всегда открывается вариант A (Фреска)
- Чтобы сохранить другой вариант по умолчанию — попросить изменить `state = { cover: 'b' }`
