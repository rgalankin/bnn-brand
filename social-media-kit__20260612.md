# Social Media Kit — Бизнес на нейронах

**Каналы:** Telegram @biznaneyronah · Instagram · YouTube  
**Правило двух шрифтов:** Cormorant Garamond (заголовки) + Space Grotesk (текст/UI). Никакого третьего.

---

## ОБЩИЕ ПРАВИЛА ДЛЯ ВСЕХ ФОРМАТОВ

**Охранная зона логотипа:**  
Минимум **24px** от любого края изображения. На мобильных preview логотип не должен обрезаться.

**Текст на изображении:**  
- Максимум **2 шрифта** на одном визуале
- Минимальный размер читаемого текста на мобиле: **28px** (в фактических пикселях файла)
- Текст НЕ размещать поверх сложных фото без тёмного overlay (`rgba(10,22,40,0.75)`)
- Никакого текста на градиентных переходах — только на однотонных или overlay

**Запрещённые фоны для наложения текста:**
- Пёстрые стоковые фото без overlay
- Яркие фото людей/природы без затемнения
- Белый текст на светло-сером фоне (нет контраста)
- Любое изображение с контрастностью фон/текст ниже 4.5:1 (WCAG AA)

**Цветовой принцип на изображениях:**  
Выбирай один доминирующий полюс:
- **Ренессанс-схема:** фон Marble White (`#F5F0E8`), акцент Gold — для ценностей, кейсов, CEO
- **Футуризм-схема:** фон Circuit Deep (`#0A1628`), акцент Teal — для агентов, автоматизации

## INSTAGRAM

### Форматы

| Формат | Размер | Применение |
|--------|--------|-----------|
| Квадрат | 1080×1080 px | Посты, галереи |
| Вертикальный | 1080×1350 px | Посты — лучший охват в ленте |
| Stories | 1080×1920 px | 16:9 вертикальный |
| Reels cover | 1080×1920 px | Обложка видео |
| Reels preview | 1080×1350 px | Preview в ленте (центр 1080×1080 — безопасная зона) |

```
│  │ (главная мысль,         │    │  Максимум 2 строки

│  │                         │    │
│  │ Body: Space Grotesk     │    │  Y=900px
│  │ 32px Marble White       │    │  Контекст/описание
│  │                         │    │
│  └─────────────────────────┘    │
│                                 │  Y=1580px — граница безопасной зоны
│  [Instagram UI zone below]      │
└─────────────────────────────────┘  Y=1920px
```

**Координаты ключевых элементов (1080×1920):**
- Логотип: X=54px, Y=160px, ширина 120px
- H1-заголовок: X=54px, Y=360px, ширина до 972px
- Метрика: X=54px, Y=680px (или по центру)
- Описание под метрикой: X=54px, Y=840px, ширина до 820px
- Нижний CTA (если есть): X=54px, Y=1480px — строго выше 1580px

### Что НЕЛЬЗЯ на обложке Reels:
- Кликбейтные лица «с открытым ртом» — инфобизнес-клише
- Красные стрелки, кружки, «СМОТРИ» — дешёвый вирус
- Стоковые картинки людей (рукопожатия, мозги)
- Синий корпоративный фон с линиями
- Более 2 шрифтов
- Текст ниже 1580px (перекроет Instagram)
